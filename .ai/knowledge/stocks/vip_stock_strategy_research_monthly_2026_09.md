## 1. 本月结论摘要

本月围绕VIP股票现有正式候选策略完成了两组研究：

1. 全局净止盈目标微调：比较净`+0.6% / +0.8% / +1.0% / +1.2% / +1.5%`；
2. 固定净`+0.8%`目标与峰值回撤辅助退出并行：比较17种峰值回撤结构。

最终结论：

- 净`+0.8%`继续定义为`CURRENT_ROBUST_BASELINE`，即当前数据、当前BUY体系下证据最强的正式锚点；
- 净`+0.8%`不是已证明的理论全局最优值，也不是长期收益上限；
- 调低到净`+0.6%`会在部分满仓区间增加少量实际BUY、减少满仓错失，但组合收益下降；
- 17种峰值回撤候选均未通过训练＋验证一致性门禁；
- 当前生产只记录峰值、谷值、MFE、MAE和峰值回撤研究事实，不会因峰值回撤自动清仓；
- 本月不提出任何正式BUY/SELL参数变更，不进入生产实施；
- 当前技术实施主目标仍是已冻结的组合基础能力：年度结算与播报、真实槽位资金回归、槽位外机会及其独立账本/消息闭环。

## 2. 当前正式业务锚点

### 2.1 BUY策略

本月研究按历史时点重建以下三个现有BUY策略：

#### DEEP_MEAN_REVERSION_BUY

适用`NARROW / RANGING / STEADY`：

```text
距30日低点 <= 0.3%
effectiveZ1 <= -2.0
return7d >= -1.0%
MA7/MA30 - 1 >= -2.0%
NARROW下effectiveZ1 = zscore1d × 0.6
```

#### RANGE_LOWER_BUY

适用`NARROW / RANGING`：

```text
30日通道宽度 <= 8%
position30 <= 10%
zscore1d <= -0.5
return6h <= 0
return7d >= -2.0%
MA7/MA30 - 1 >= -2.0%
```

#### STRICT_REBOUND_CONFIRM_BUY

适用`WEAK / DECLINER`：

```text
距30日低点 <= 0.5%
return1d > 0
zscore1d >= 0.8
referencePrice <= MA30 × 1.002
```

候选排序：

```text
qualityScore DESC → stocksId ASC
```

同一股票同时命中多个策略时只形成一个候选，主策略按质量分最高、同分策略编码升序确定。

### 2.2 正式SELL基线

```text
净收益 >= +0.8%                    → TARGET
净收益 <= -1.5%                    → RISK
持有时间 >= 14天                   → TIME
RANGE且净收益>0且position30>=0.60 → RANGE
```

净收益统一扣除0.1%卖出费：

```text
netReturn = exitPrice / entryPrice × 0.999 - 1
```

正常退出冷却24小时，风险退出冷却48小时；平仓后必须观察到BUY条件恢复为false，才能接受下一次false→true边沿。

### 2.3 资金与成交

```text
正式组合：5槽
每槽初始资金：2.00b
总初始资金：10.00b
整数股数
余款留在原槽
卖出所得回到原槽并继续复利
```

当前bar只产生决策，BUY与SELL都使用紧邻下一根严格连续且可用的15分钟bar成交。缺少紧邻bar时fail-closed，不跨断层寻找远期价格。

- 原始BUY条件命中与false→true边沿；

- 因满仓错失的BUY；
- 持有时间、槽位利用率、收益和最大回撤。

所有参数组的原始BUY机会必须一致；每个5槽参数组必须从`10.00b`起点独立连续重放。

### 4.6 调低目标是否增加BUY

净`+0.6%`相对净`+0.8%`：

| 区间 | 实际成交BUY变化 | 满仓错失变化 |
|---|---:|---:|
| 训练段 | +2 | -20 |
| 验证段 | 0 | 0 |
| 已消费观察段 | +1 | -14 |

结论：

- 调低SELL目标不增加原始BUY信号；
- 它可能因更早释放槽位增加实际成交BUY；
- 但成交数量不保证严格单调，因为不同退出路径会接入不同股票并改变后续槽位占用；
- 本次新增周转没有带来更高收益。

训练段中，净`+0.6%`相对T08新增或替换进入的9笔完成交易平均净收益约`+0.1377%`；被替换掉的7笔T08交易平均净收益约`+0.6654%`。因此更早卖出虽然获得更多机会，却放弃了质量更高的后续持有收益。

## 5. 峰值回撤辅助退出研究

### 5.1 生产现状

当前生产批次保存：

```text
peakPrice / troughPrice / MFE / MAE / peakDrawdown / currentNetReturn
```

并预留`CLOSED_DYNAMIC`和`dynamicSellState`，但动态SELL未形成可执行规则：

```text
dynamicShadowDecision = NOT_EVALUATED
dynamicShadowReason = DYNAMIC_RULE_NOT_FROZEN
```

因此当前生产不会因峰值回撤自动清仓，峰值数据只用于研究遥测。

现有累计`peakDrawdown=(历史troughPrice-历史peakPrice)/历史peakPrice`也不能直接用作未来清仓触发，因为谷值可能先于峰值。未来若重新研究，触发量应为当前价相对峰值：

```text
currentPeakDrawdown = currentPrice / peakPrice - 1
```

或扣费净收益回吐：

```text
absoluteGiveback = peakNetReturn - currentNetReturn
```

### 5.2 研究变量

保持T08、BUY、止损、14天、RANGE退出、资金和成交规则不变，比较17种峰值回撤辅助出口：

- A族6种：激活`+0.4%～+0.7%`，固定回吐`0.20/0.30`个百分点；
- R族4种：激活`+0.4%～+0.6%`，只保留峰值利润的50%或65%；
- W族3种：回撤后要求`return6h<0`，或同时要求`zscore1d<0`；
- P族2种：回撤条件连续两根15分钟bar成立；
- H族2种：至少持有48小时才允许回撤退出。

优先级：

```text
TARGET → RISK → PEAK_DRAWDOWN → TIME → RANGE
```

### 5.3 5槽结果摘要

训练段B0为`+2.9846%`。只有`H60D20H48`略高至`+3.0281%`，提升仅`+0.0436`个百分点；但同BUY配对结果为负，说明改善来自槽位路径偶然替换，不是峰值退出具有更高单笔期望。

验证段B0为`+0.5392%`，17个候选全部低于B0。最接近的`A70D30`为`+0.4649%`，仍低`0.0744`个百分点。

已消费观察段少数方案略高：`R50P50 +0.5850%`、`A60D30 +0.5830%`、`A70D30 +0.5248%`，但它们在训练和验证中均落后，不能据此选参。

### 5.4 固定相同BUY的配对结果

- 没有任何候选在训练、验证、已消费观察三段的平均配对差都为正；
- 验证段所有候选都低于继续使用T08；
- 已消费观察段所有候选也都低于T08；
- 峰值退出后真正优于B0自然路径的事件比例，训练/验证通常只有约13%～25%，观察段多数仅0%～7%。

结论：当前BUY体系具有明显均值回归属性。达到一定浮盈后的短时回撤通常不是永久反转，过早清仓容易错失后续恢复。

### 5.5 各增强结构为何未解决问题

- `return6h<0`与`zscore1d<0`仍会把正常回调识别为反弹衰竭；
- 连续两根15分钟bar只确认约30分钟，对当前持仓周期仍过短；
- 48小时门禁只在训练组合偶然略正，验证和观察均失败；
- 峰值利润保留比例只在已消费窗口出现局部改善，不具备跨期稳定性。

### 5.6 峰值回撤决策

```text

生产动作：不实施
研究等级：未达到SHADOW_CANDIDATE
```

## 6. 本月收益数字的周期口径

本月表格中的收益不是统一意义上的“月收益率”，而是各自独立评价窗口内，5槽组合从窗口期初权益到解析尾窗最终权益的**区间收益率**：

```text
intervalReturn = finalEquity / initialEquity - 1
```

具体解释：

- “训练段收益”对应6月新开仓机会，但允许6月内建立的持仓在7月15日前按最长14天生命周期完成退出；
- “验证段收益”对应7月新开仓机会，允许在8月15日前完成退出；
- “已消费观察段收益”只允许8月1日至8月20日新开仓，持仓可解析到9月2日；
- 各窗口为了比较参数会重新初始化`10.00b`组合，不能把三个区间收益直接相加当作连续账户收益；
- 它们接近“按开仓月份分组的策略窗口收益”，但不等于严格自然月1日00:00至月末24:00的正式月收益；
- 本月研究没有用短窗口收益冒充年度收益或未来承诺。

正式自然月/月度报表应使用连续生产账本在自然月边界的权益：

```text
月收益率 = 月末边界权益 / 月初边界权益 - 1
```

跨月持仓不强制平仓，按边界盯市权益归属月份。

## 7. 当前实施主目标

本月策略研究没有改变正式基线，因此技术实施仍应围绕本节已完整列出的业务规则完成以下闭环。本节本身可以独立作为实施目标摘要和业务验收依据，不要求读者另行查找研究产物。

### 7.1 年度结算与年报

- `Asia/Shanghai`每年1月1日00:00结算上一自然年；
- 年报使用边界权益，不强制卖出跨年持仓；
- 期末权益=`可用现金＋预留资金＋持仓可变现市值`；
- 持仓估值扣0.1%卖出费；
- 缺少合法边界行情时不得伪造结算；
- 首个不完整年度同时展示实际区间收益和年化折算，并标注试运行；
- 金额统一展示`X.XXb`。

### 7.2 槽位资金回归与展示基准重置

这里的“资金回归”必须理解为卖出资金回到原槽并继续复利：

```text
shares = floor(slotCash / entryPrice)
实际成本 = shares × entryPrice
余款保留原槽
卖出所得 = shares × exitPrice × 0.999
卖出所得回到原槽
```

年度“重置”只重置展示基准：

```text
新年度baselineEquity = 上年closingEquity
```

不得：

- 把槽位现金重置回`2.00b`；
- 修改持仓、股数、成本、批次和冷却；
- 直接修改`availableCash`伪造资金恢复；
- 合并5个槽位为单一共享现金池。

### 7.3 槽位外机会

槽位外机会必须是：

```text
正式BUY全部资格通过
AND 唯一未接纳原因是5槽已满
AND 紧邻下一bar与价格偏离均通过
```

它需要独立批次、独立BUY/SELL配对和独立统计：

- 不占正式5槽；
- 不进入正式组合权益、收益、年报和槽位利用率；
- 不因后来释放正式槽位而转为正式批次；
- 停止新增槽外BUY时，已有槽外批次仍继续管理SELL；
- 群消息必须标记“按个人持仓决定”。

### 7.4 验收重点

```text
孤儿SELL = 0
重复BUY = 0
重复SELL = 0
数据断层成交 = 0
未复位重入 = 0
同股多正式开放批次 = 0
槽位超卖 = 0
SELL静默丢弃 = 0
```

正式组合、槽位外机会、候选影子、无限影子和拒绝观察的资金与收益必须完全隔离。

## 8. 基线是否会自动升级

不会。

必须区分三件事：

1. **生产运行与资金复利**：当前冻结规则运行后，卖出所得会回到原槽继续复利，这是账本自然运行，不叫策略升级；
2. **月度风格状态更新**：股票风格、成熟度和风险可以按冻结公式逐月重算/确认，这属于现有规则的数据状态更新，也不等于BUY/SELL规则升级；
3. **规则或参数升级**：修改净止盈、BUY门槛、峰值回撤、止损、持有期、RANGE阈值或策略适配关系，必须由研究负责人再次验证、形成新规则版本并审批，系统不得自动调参或自动替换生产基线。

正式基线的复审节奏：

- 月度：追加新行情，评估冻结策略表现、风格变化、槽位外机会和本月失败假设；
- 季度：或新增足够独立交易后，判断是否值得提出新策略版本；
- 新候选：先预注册，训练/验证/未消费证据通过后，才可定为`SHADOW_CANDIDATE`；
- 升级生产：还需不少于20个自然日前向Shadow、消息与资金状态机验收，并获得单独业务审批；
- 任何影响交易结果的改动都必须产生新规则版本，禁止自动调参和自动上线。

因此，当前T08会继续运行，但它不会因为新月份到来自动变成T10、T12或加入动态SELL。是否升级仍需再次研究、验证和确认。

## 9. 2026-10研究方向

### 9.1 保持T08不动，先积累未消费证据

下月首要任务不是再次搜索`0.1%`级阈值，而是用新增行情评价冻结T08：

- 自然月正式/影子连续账本收益；
- MDD、持有时间、槽位利用率；
- 原始BUY、实际BUY和满仓错失；
- 槽外机会理论收益及其对正式组合的机会成本；
- 三个BUY族的独立贡献；
- 单股、单月和少数交易集中度。

### 9.2 动态SELL改变结构，不再密集搜索简单回撤

下一次动态SELL应从“回撤多少”转向“恢复是否真正失败”：

```text
接近T08
AND 峰值后经过较长时间未创新高
AND 回撤后多次恢复失败
AND 6小时/1日中周期趋势共同转弱
```

需要考虑：

- 距峰值时间；
- 峰值后未创新高持续时间；
- 恢复失败次数；
- 6小时与1日联合趋势，而不是单根/两根15分钟bar；
- 按DEEP/RANGE/REBOUND分策略适用。

其中：

- DEEP应给予最长恢复时间；
- RANGE已有区间恢复出口，峰值规则需避免重复；
- REBOUND可能最适合较主动利润保护，但必须单独验证。

在规则预注册前不读取生产动态SELL遥测结果选参数；在新未消费证据到来前不升级。

### 9.3 优先研究槽外机会质量

第一阶段已证明，降低止盈可以减少满仓错失，却未提高收益。因此下月更有价值的问题是：

> 被正式5槽拒绝的机会本身是否持续具有正期望，以及什么情况下值得提高容量或改进排序？

必须使用独立槽外账本回答，而不是通过降低止盈强行释放槽位。

研究至少输出：

- 槽外机会数量、理论成交率和策略族；
- 独立收益、胜率、MFE/MAE和持有时间；
- 与当时占槽旧仓的反事实差；
- 如果增加第6槽，完整组合收益、MDD和利用率如何变化；
- 收益是否集中于单股或单月。

### 9.4 不做事项

- 不以达到约20%历史年化为研究上限；
- 不因一个新月份表现好就自动改参数；
- 不在已消费历史上继续扩大峰值回撤网格；
- 不把动态SELL数据采集数量当作建议或收益；
- 不以更多BUY数量代替组合收益质量；
- 不把年化折算写成未来承诺。

## 10. 证据等级与最终决策

| 项目 | 本月等级 | 决策 |

最终冻结结论：

```text
BUY规则保持不变
净止盈保持+0.8%
硬风险保持-1.5%
最长持有保持14天
RANGE恢复保持position30>=0.60且盈利

```

本月研究虽未提高生产基线收益，但明确排除了低止盈和简单峰值回撤两条看似提高周转、实则损害均值回归收益的路径。下月应优先使用新增未消费数据评价T08、槽外机会质量与恢复失败型动态SELL，而不是继续密集搜索短周期回撤阈值。
